<Heading id="weights">A 比 B 多出的个头，值多少分？</Heading>

先统一两把尺子的刻度。把果径 55–80 mm 映射到 0–1，把橙色面积除以 100。于是 A 的两项读数是 (0.8, 0.4)，B 是 (0.4, 0.8)。A 在个头上领先 0.4，恰好也是 B 在颜色上的领先量。

给每项读数乘上一个权重，再把两份贡献相加，这就是**加权分**。如果果径权重取 1、颜色权重取 1.5，A 得 0.8 + 0.6 = 1.4 分，B 得 0.4 + 1.2 = 1.6 分。原来的测量值一项都没动，机器的偏好已经体现在分差里了。

<TheoryNote title="什么时候会刚好打平？">

记果径权重为 w₁、颜色权重为 w₂。A 与 B 的加权分之差是 0.4w₁ − 0.4w₂。两个权重相等时并列；果径权重较大时 A 领先，颜色权重较大时 B 领先。这条简便判断用到了这两颗样果恰好对称的读数。

</TheoryNote>

<Heading id="bias">整盘挑严一点，哪颗先退出？</Heading>

给每颗果子的加权分都加上同一个数 **b**，得到总分 **z**。本课约定 z 达到零就入选，刚好等于零也收。比如 b = −1.4，加权分就得达到 1.4。要把展台挑严一些，可以把 b 调得更负。

这个统一加上的量叫**偏置**。两颗果子各扣相同的分，它们的分差仍然一样。图上的入选线会平行移动，你能看到某颗果子退出，盘内的排名却维持原样。

<TheoryNote title="为什么这还是第二课的那条直线？">

把归一化的两项测量记作 x₁ 和 x₂。线上的点满足 w₁x₁ + w₂x₂ + b = 0。权重决定两个方向上的分数变化率；权重固定时，改变 b 只改变零分线的位置。在果径和颜色的原始刻度上，两个输入都只做了线性缩放和平移，边界依然是直线。

</TheoryNote>

<Heading id="activation">过线的信号一定得跳一下吗？</Heading>

**一个神经元**先把输入乘权重、加偏置，再把 z 交给一个函数，把分数变成输出。这个最后的函数叫作**激活函数**。如果输出直接接分拣开关，硬门槛很好理解：z 小于零就给 0，一到零就给 1。

也可以让输出保留「离门槛有多远」的信息。Sigmoid 把 z 平滑地映到 0 与 1 之间，零分处恰好输出 0.5。对照 A 果在线前、线上和线后的读数：只多一个百分点的橙色，硬门槛可能跳了一整格，Sigmoid 则只变一点。若店员最后仍需一个箱号，按 Sigmoid 输出达到 0.5 来选，会收进同一批果子。这一课的输出描述你设定的偏好；要把数值解释成实际被店员选中的概率，还需要选择记录来检验。

<TheoryNote title="0.5 为什么与零分对齐？">

Sigmoid 的公式是 σ(z) = 1 / (1 + exp(−z))。代入 z = 0 得到 1/2；z 增大时分母变小，函数严格递增。所以 σ(z) ≥ 0.5 与 z ≥ 0 给出相同的入选决定。

</TheoryNote>
