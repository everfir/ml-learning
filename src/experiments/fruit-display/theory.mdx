<Heading id="weights">一张打分单，为什么总要漏一头？</Heading>

拿 A 和 B 的两个读数分别取平均，得到的就是 C。比如只看个头，2 和 8 的平均值是 5；换成「橙色减个头」，6 和 −6 的平均值是 0。你可以在工作台试任意一组权重：**C 的总分总在 A 和 B 中间**。当 A、B 都够进礼盒时，C 也够了。三颗果子已经足以说明这个打分器的限制。

<TheoryNote title="加一个偏置能绕开中点吗？">

写成 s(x) = w₁x₁ + w₂x₂ + b。C 的输入是 A、B 输入的平均值，因此 s(C) = (s(A) + s(B)) / 2，包括 b 在内也成立。若 s(A) 和 s(B) 都达到门槛，s(C) 也达到。把门槛平移、调换权重或翻转正负都绕不开这个事实。

</TheoryNote>

<Heading id="bias">多问一次，还得让两份答案留得住</Heading>

第一路算「橙色减个头」，专找小而橙的线索。第二路调换加减方向，专找大而青的线索。给 A 果两张打分单，得到 6 和 −6。第二张单子其实没发现自己要找的东西。如果直接相加，它却会把第一路找到的 6 分全部扣光。对 B 果，两张单子的处境刚好互换。

<TheoryNote title="两张不同的线性打分单直接相加呢？">

把两路的权重逐项相加，就得到了一张等效的打分单。本实验的第二路恰好将权重全部取反，合计恒为零。即便两路权重可以独立选，只要中间仍然只做线性计算，再线性相加，依然绕不开中点限制。

</TheoryNote>

<Heading id="activation">让没找到线索的一路报零</Heading>

现在给两路各加一道开关：正分留下，负分记零。这道规则叫 **ReLU**。拿 A 走一遍，第一路输出 6，第二路输出 0；拿 B 走一遍，两路分别输出 0 和 6。C 则是两路都报 0。把处理过的分数相加，再检查是否达到 3 分，三颗终于都去对了地方。

在这套权重下，两路合计正好是两个输入相差的分数。差 3 分的 (7，4) 要进礼盒；差 2 分的 (7，5) 留在散装。门槛若设成 5，即使三个老样例全对，第一颗新果仍会漏装。

<TheoryNote title="这张接线图怎么读成一个 MLP？">

两个输入同时送给两个中间神经元。每个神经元做一次加权求和并经过非线性激活，这是一个隐藏层。输出层取两个隐藏值，分别乘以 1 再相加，与门槛比较。减去门槛再检查是否非负，等价于给输出层设置一个负的偏置。这样只向前传递、有隐藏层的网络是一个小型多层感知机（MLP）。一般网络里的两路权重可以独立学习；这里把第二路取反是为了单独看清两种线索。

</TheoryNote>

<TheoryNote title="Sigmoid 也能放在神经元后面吗？">

可以。Sigmoid 把实数平滑地压到 0 与 1 之间。ReLU 则保留正分的大小，把负分截到零，本课据此可以直接算出两项的绝对差。更换激活函数时，应重新验证网络的权重、门槛和预测。

</TheoryNote>
