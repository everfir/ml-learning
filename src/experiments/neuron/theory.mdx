<Heading id="neuron">一个神经元做了什么？</Heading>

输入 **x** 先乘以权重 **w**，再加上偏置 **b**。得到的加权输入 **z = wx + b** 会交给激活函数，产生输出 **a = f(z)**。

<Heading id="weights">输入、权重与偏置</Heading>

固定权重和偏置，拖动输入 x。图上的橙点沿着曲线移动，横坐标就是新的 z。

**试一试**　把 w 调为 0。再拖动 x，观察 z 是否变化。此时只有偏置 b 决定输出。

<Heading id="activation">为什么需要激活函数？</Heading>

选择 Linear 时，输出等于 z。即使串联多个这样的神经元，合成后仍是输入的一次函数或常数。加入非线性激活后，网络才有机会拟合弯曲的关系。

- **Sigmoid** 把实数映射到 0 和 1 之间。两端接近平坦，同样的输入变化对输出的影响更小。
- **ReLU** 把负值变为 0，正值原样通过。
- **Tanh** 的输出在 −1 和 1 之间，穿过原点。
- **Linear** 保留加权输入，可以作为比较基准。
